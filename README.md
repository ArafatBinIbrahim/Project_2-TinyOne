# TinyOne – App Showcase Landing Page

TinyOne is a bold, high-contrast landing page template designed to showcase mobile apps, products, and inspiration galleries. With its striking yellow-and-black theme, it's built to grab attention and highlight cross-platform app availability.

## ✨ Features

- **Hero Section** – "Inspire your inspiration" headline with description, device mockup carousel (phone/tablet preview), and platform icons (Windows, Android, Apple)
- **Carousel Indicators** – Dot navigation for cycling through hero device previews
- **TinyOne Features** – Six-feature grid with icons: Fully Responsive, Fully Layered PSD, Font Awesome Icons, HTML3 & CSS3, Email Template, Free to Download
- **Newsletter Signup** – "Keep in touch with us" dark section with email input and "Submit" button
- **Social Links** – Facebook, Twitter, Google+, Pinterest icon buttons
- **Footer** – Company info (HALOVIETNAM LTD, address, email, phone) and five link columns: Examples/Shop/License, Contact/About/Privacy/Terms, Download/Support/Documents, Media/Blog/Forums
- **Responsive Navigation** – Hamburger menu for mobile-friendly browsing

## 🚀 Getting Started

Since this is a static HTML template, no build step is required.

```bash
git clone https://github.com/your-username/tinyone.git
cd tinyone
# Simply open index.html in your browser
```

Or serve locally:

```bash
npx serve .
```
